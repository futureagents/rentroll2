# P-02 · Settlement statement (print view)

Source: UI/UX Specification v1.0, Part D, "Print views". Module M-8 (product.md §6). Connection C-10 (product.md §12).

## Contents

Tenancy dates · deposit held · each deduction with reason and thumbnail · total · balance refundable or owed · space for both signatures

## Rules (all print views)

Each print view is a separate page with no navigation, no buttons and a white background, opened in a new tab with the print dialog triggered on load. Do not attempt to hide the app's own interface with print styles.

Opened from: L13-BTN-PRINT ("Opens P-02").

Related L-13 rules: if deductions exceed the deposit, the balance shows as an amount owed by the tenant and "the statement wording changes accordingly". Once marked settled, the statement becomes read-only; corrections require a new statement that references the first.

Build tracker done-when (with L-13): "Deductions pull from repair history with photos attached".
