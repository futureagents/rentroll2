# P-03 · Door QR card (print view)

Source: UI/UX Specification v1.0, Part D, "Print views". Connection C-11 (product.md §12).

## Contents

Unit number · property name · the QR · one line: "Scan to report a problem" · landlord's phone as a fallback. Sized four to an A4 page.

## Rules (all print views)

Each print view is a separate page with no navigation, no buttons and a white background, opened in a new tab with the print dialog triggered on load. Do not attempt to hide the app's own interface with print styles.

Opened from: L08-BTN-PRINTQR ("→ P-03, one card per selected unit") · E2-03 action "Print door QR codes". L09-BTN-QR "Shows the unit QR in a modal with a print option".

Build tracker done-when: "Four to a page, scannable from print".
