# P-01 · Rent receipt (print view)

Source: UI/UX Specification v1.0, Part D, "Print views". Connections C-2, C-10 (product.md §12).

## Contents

Landlord name and logo · receipt number · tenant · unit · month · amount in figures and words · date received · payment reference · payment QR · a signature line

## Rules (all print views)

Each print view is a separate page with no navigation, no buttons and a white background, opened in a new tab with the print dialog triggered on load. Do not attempt to hide the app's own interface with print styles.

Opened from: L04-BTN-RECEIPT ("Opens P-01 in a new tab") · T05-BTN-PRINT ("Opens P-01 for that receipt").

Build tracker done-when: "Prints cleanly to A4 with the landlord's branding".
