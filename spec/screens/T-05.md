## Open questions

> OPEN: Showing amounts contradicts G-2 ("No tenant-facing screen ever queries or displays rent amounts"), PR-3 ("The tenant's pages never show rent figures") and product §8 ("The tenant side has no path to any money screen"). The T-04 note states the exception; the global rules do not.
> OPEN: P-01 includes "payment QR" and "amount in figures and words". Opened from T-05 it is a tenant-facing view. Does P-01 from T-05 render the same contents?
> OPEN: Receipts for which tenancy — the current one only (as T-03), or all of this tenant's?
> OPEN: Voided/undone payments (L-04 Undo) — do they appear?
> OPEN: T05-BTN-PRINT is a 32×32 icon button vs the 48×48 tenant touch-target minimum (A4).
> OPEN: No entry point to T-05 is specified (see T-04).
