## Components

| ID | Type | Content · what happens |
|---|---|---|
| T03-LST-REPORTS | List | Every request from this unit's current tenancy. Each shows: number, category, date, status chip, and the landlord's latest update if any. |
| T03-CHP-STATUS | Status chip | Received · Assigned · In progress · Done. Plain words, no internal jargon. |
| T03-TML-ITEM | Timeline | Expanding a report shows its history — reported, assigned, updated, completed — with the tenant-safe wording only |

## Open questions

> OPEN: "the landlord's latest update if any" — what text is this? The landlord's updates are sent via S-01 outside the system (WhatsApp/copy). Is the sent message text stored and shown here? L-07 forbids exposing internal notes.
> OPEN: "tenant-safe wording" is not defined beyond the four status words.
> OPEN: Status mapping L-06 → T-03: New → Received, Assigned → Assigned, In progress → In progress, Done → Done (assumed). What does a reopened request show?
> OPEN: Category shown — the tenant's choice or the assistant's/landlord's edited category (L07-SEL-CATEGORY)?
> OPEN: Requests logged by the landlord via L06-BTN-NEW for this unit — do they appear here?
