# L-03 · Portfolio dashboard

Source: UI/UX Specification v1.0, Part B. Module M-1 (product.md §6). Wireframe A (product.md §7).

## Meta

| | |
|---|---|
| ROUTE | `/` |
| ACCESS | Signed in |
| PURPOSE | Answer one question in five seconds: is anything wrong today? Everything on this screen is either a number or a problem with a fix button next to it. |
| LEADS TO | L-04, L-06, L-12, and directly into S-01 |

The screen map calls L-03 "the hub": "The dashboard is the only hub; every other landlord screen is reachable from the sidebar as well."

## Layout

Top to bottom: page header · four stat cards in a row · income chart · Needs attention list. Nothing else. Resist adding a second chart.

## Interactions

| Trigger | Result |
|---|---|
| L03-CRD-DUES | Route to L-04 with the Overdue filter already applied |
| L03-CRD-EXPIRING | Route to L-12 with the 90-day filter applied |
| L03-CRD-OCCUPANCY | Route to L-08 filtered to vacant units |
| L03-CRD-COLLECTED | Route to L-04 for the current month, no filter |
| L03-ROW-ATTENTION | Route to the relevant detail — rent rows to L-05, requests to L-07, agreements to L-12 |
| Row action "Remind" (L03-BTN-ROWREMIND) | Opens **S-01** directly, without navigating away. Closing S-01 returns to the dashboard with the row refreshed. |
| Row action "Open" (L03-BTN-ROWOPEN) | Opens the relevant detail panel over the dashboard |

## Needs attention — what appears and in what order

| Order | Item | Condition |
|---|---|---|
| 1 | Urgent maintenance request | Urgency = urgent and status is not closed |
| 2 | Rent overdue 10+ days | Unpaid and past due by 10 or more days |
| 3 | Agreement expiring within 30 days | Agreement end date minus today ≤ 30 |
| 4 | Rent overdue 1–9 days | Unpaid and past due |
| 5 | Open maintenance request | Any other open request, oldest first |
| 6 | Agreement expiring within 90 days | Agreement end date minus today ≤ 90 |

## States

| State | Display |
|---|---|
| Loading | Skeleton shapes in place of the four cards and six list rows. Never a full-page spinner. |
| Nothing wrong | The Needs attention card shows: "Nothing needs your attention today." with a tick icon. This is a deliberate reward state, not an empty state. |
| No data at all | Only reachable if L-02 was skipped. Shows "Add your first property to see your dashboard" with a button to L-08. |
| Load failure | Card-level: each card shows a retry link. One failed card does not blank the page. |

## Rules and open questions

> OPEN: Wireframe A orders Needs attention as rent 18d → agreement 22d → urgent geyser → rent 5d, contradicting order rule 1 (urgent first). The rules table above is taken as authoritative unless decided otherwise.
> OPEN: Ordering within each group is given only for item 5 ("oldest first"). Order within groups 1, 2, 3, 4 and 6 is not stated.
> OPEN: Items 3 and 6 overlap (≤30 is also ≤90). Assumed each agreement appears once, in the highest group.
> OPEN: Already-expired agreements (end date minus today < 0) satisfy "≤ 30". L-12 puts them at the top in danger colour. Their position here is not stated.
> OPEN: Which items take which action button? "Remind" is shown for rent rows in the wireframe and "Open" for the urgent request; agreement rows show no button in the wireframe. The row spec says "one action button".
> OPEN: "Rent overdue" — "past due" is measured from the rent entry's due date. For part-paid rows (L-04), is the item still "Unpaid"?
> OPEN: Row action "Open" opens the panel "over the dashboard", but A4 says over 1024px "detail panel opens alongside rather than over content". Agreements have no detail panel (L-12 is a table).
> OPEN: The "No data at all" button goes to L-08 with the text "Add your first property", but L-08 has only "Add unit" (with a property field) and no add-property flow anywhere.
> OPEN: "Status is not closed" (item 1) — L-06 statuses are New · Assigned · In progress · Done. "Closed" is assumed to mean Done.
> OPEN: L03-CRD-COLLECTED "Sub-line compares to last month" — format not given. L03-CRD-OCCUPANCY / L03-CRD-DUES sample values are examples.
> OPEN: Scope journey "Warns at 90, 60 and 30 days". There is no 60-day item here.
