# L-11 · Tenant detail

Source: UI/UX Specification v1.0, Part B, section "L-10 · Tenant list · L-11 · Tenant detail" (one table in the source, split here by ID prefix). Module M-6 (product.md §6).

## Meta

| | |
|---|---|
| ROUTE | `/tenants/:tenantId` |
| PURPOSE | Contact, agreement and payment history for a person, past or present. |

## Components

| ID | Type | Content · what happens |
|---|---|---|
| L11-SEC-CONTACT | Contact block | Phone with call, message and copy buttons; email with a mail button if present |
| L11-SEC-AGREEMENT | Key-value block | Start, end, rent, deposit paid, notice status, with a countdown when within 90 days |
| L11-SEC-PAYMENTS | Table | Every rent entry for this tenant, with a paid-on-time percentage at the top |
| L11-SEC-DOCS | File list | Agreement, ID proof, anything else uploaded. Each with download and share. |
| L11-BTN-ENDTENANCY | Danger button | "End tenancy" → confirm dialog → routes to L-13 with this tenant selected |
| L11-BTN-SENDAGREEMENT | Quiet button | Opens the email composer with the agreement referenced. Helper text: "Attach the file after your email app opens." |

## Open questions

> OPEN: "paid-on-time percentage" — "on time" is not defined (on or before the due date? within a grace period?).
> OPEN: "notice status" is displayed, but no control sets it (see L-12).
> OPEN: Agreement start/end/rent are a single set of values (product.md §15 puts them on TENANT). After a renewal (L12-BTN-RENEW), previous terms are not shown.
> OPEN: "Opens the email composer" — is this S-01's "Email instead" path or a direct `mailto:`? S-01 is not listed as opened from L-11.
> OPEN: "message" button on L11-SEC-CONTACT — no interaction defined (see L-05).
> OPEN: Upload of documents to L11-SEC-DOCS is not specified.
> OPEN: "End tenancy → … routes to L-13". The tenancy actually closes at L13-BTN-CLOSE "Mark settled". Between End tenancy and Mark settled, is the tenancy still active? Is the tenant link still valid?
> OPEN: Product M-6 lists "rent paid to date, deposit held" and "share the unit link" — not on L-11.
> OPEN: Whether L-11 is a full page or a panel is not stated (L-10 row click "→ L-11").
